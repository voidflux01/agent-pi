A 子代理收派 — 派活 / 追问 / 续跑 / 杀停 / 纠偏 / 应答 8

sub 派一个子代理跑临时活

开新 SA + widget，受控并行。

/sub 让 scout 审计 YAML 解析注入面
subcont 就同一个子代理追问/迭代

续聊，上下文不丢，不开新进程。

/subcont 3 展开第 2 条给修复 diff
subresume 断点续跑持久化子代理

会话断/压缩后从 journal 恢复。

/subresume <journal-id> 收尾调研
subrm 杀掉并移除指定子代理

误派/跑偏立刻止损（会 kill）。

/subrm 4
subclear 全清子代理收场

杀全部 running + 清屏重开。

/subclear
nudge 中途纠正运行中 worker

定向 steer，不杀重派。

/nudge reviewer 只看本次 diff
asks 看子代理挂起向你问的问题

ask_parent 待办列表。

/asks
ask-answer 回答挂起提问让它继续

给答案 → agent 解挂继续跑。

/ask-answer <id> 留 LEGACY 默认
